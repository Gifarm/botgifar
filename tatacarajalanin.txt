# Cara menjalankan Flow Music Bot v3.0.0

## Paling mudah
```
./run_app.sh
```
(atau klik dua kali run_app.bat di Windows)

## Di dalam aplikasi
1. Atur jumlah browser (default 5).
2. Klik kartu "Browser 1" -> login manual di jendela yang terbuka.
3. Klik tombol "Sembunyi" di kartu.
4. Ulangi untuk browser lain.
5. Pilih file .txt prompt (satu prompt = satu paragraf, dipisah baris kosong).
6. Klik JALANKAN BOT.

Hanya browser yang sudah dibuka yang dipakai. Browser lain yang masih
tertutup tidak ikut dijalankan.

Browser akan bekerja di belakang layar (diminimalkan lewat CDP),
jadi tetap bisa dipakai Zoom atau aplikasi lain.

## Kalau satu browser error / kena limit
Kartu browser menampilkan merah, mis. "Macet — klik Cek (#12)" atau
"Limit — klik Cek (#12)". Prompt terakhirnya DITAHAN, tidak hilang.
1. Buka browser itu (klik kartu / tombol Buka).
2. Perbaiki manual: login ulang, buat session baru, ganti akun, dsb.
3. Klik tombol "Cek" di kartu browser itu.
Bot mengecek lagi lalu mem-paste ulang prompt yang sama dan lanjut bekerja,
tanpa menghentikan browser lain atau me-restart seluruh bot.

## Hasil
- Musik: folder downloads/
- Status prompt: folder state/run_<tanggal>/
- Log: bot.log

## Mode CLI (opsional)
```
./venv/bin/python main.py --login --browsers 5
./venv/bin/python main.py --browsers 5 --prompt "promt_lagu/100_prompt_lagu_v30_bangunan.txt"
```
