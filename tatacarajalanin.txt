# Cara menjalankan Flow Music Bot v3.1.0

## Paling mudah
```
./run_app.sh
```
(atau klik dua kali run_app.bat di Windows)

## Di dalam aplikasi
1. Atur jumlah browser (default 5).
2. Klik kartu "Browser 1" -> login manual di jendela yang terbuka.
3. Klik tombol "Sembunyi" di kartu.
4. Ulangi untuk browser lain.
5. Pilih file .txt prompt (satu prompt = satu paragraf, dipisah baris kosong).
6. Klik JALANKAN BOT.

Hanya browser yang sudah dibuka yang dipakai. Browser lain yang masih
tertutup tidak ikut dijalankan.

Browser akan bekerja di belakang layar (diminimalkan lewat CDP),
jadi tetap bisa dipakai Zoom atau aplikasi lain.

## 4 tombol di setiap kartu browser
- Buka/Tampilkan : membuka / memunculkan jendela browser.
- Sembunyi       : menyembunyikan browser; bot tetap bekerja.
- Cek            : menjalankan / melanjutkan browser ini (setelah error,
                   setelah di-Stop, atau browser baru yang dibuka di tengah run).
- Stop           : menghentikan HANYA browser ini. Browser lain tetap bekerja.
                   Prompt-nya ditahan (tidak hilang); klik Cek untuk lanjut.

## Menambah browser di tengah jalan (mis. 3 -> 4)
Naikkan "Jumlah" browser (boleh saat bot berjalan), buka kartu browser baru,
login, klik "Sembunyi", lalu klik "Cek" di kartunya. Browser itu ikut
mengambil prompt yang masih tersisa tanpa mengganggu browser lain.
Menurunkan jumlah browser baru bisa setelah bot di-STOP.

## Kalau satu browser error / kena limit / di-Stop
Kartu browser menampilkan merah, mis. "Macet — klik Cek (#12)",
"Limit — klik Cek (#12)", atau "Dihentikan — klik Cek (#12)".
Prompt terakhirnya DITAHAN, tidak hilang.
1. Buka browser itu (klik kartu / tombol Buka).
2. Perbaiki manual: login ulang, buat session baru, ganti akun, dsb.
3. Klik tombol "Cek" di kartu browser itu.
Bot mengecek lagi lalu mem-paste ulang prompt yang sama (atau melanjutkan
unduhan lagu yang sudah jadi) dan lanjut bekerja, tanpa menghentikan browser
lain atau me-restart seluruh bot.

Kalau SEMUA browser di-Stop padahal prompt masih ada, bot tetap berjalan.
Kamu bisa memakai tombol "Cek Lagu Ganda" dulu, lalu klik Cek di browser mana
pun untuk melanjutkan. Untuk mengakhiri sesi, tekan tombol STOP besar.

## Hasil
- Musik: folder downloads/
- Status prompt: folder state/run_<tanggal>/
- Log: bot.log

## Pemeriksaan file ganda
Semua browser mengunduh langsung ke SATU folder downloads/ (tanpa subfolder
per browser). Proses download diantrekan supaya tidak saling menimpa file.
Ada dua cara memeriksa:
1. Otomatis setelah semua prompt habis (bot selesai normal). Semua file audio
   dikumpulkan jadi satu daftar, duplikatnya disusun, lalu dihapus sendiri.
2. Tombol "🧹 Cek Lagu Ganda" — bisa ditekan KAPAN SAJA, termasuk saat prompt
   masih dikerjakan atau semua browser di-Stop. Bot tidak dihentikan. Mode ini
   aman: file sementara .crdownload dan folder kerja tidak disentuh.

Hanya file yang nama + isinya sama persis yang dihapus; file berbeda tetap
disimpan. Daftar file yang dihapus muncul di log dan dialog ringkasan.

## Mode CLI (opsional)
```
./venv/bin/python main.py --login --browsers 5
./venv/bin/python main.py --browsers 5 --prompt "promt_lagu/100_prompt_lagu_v30_bangunan.txt"
```
